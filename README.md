The mod adds tea and coffee trees, as well as a realistic system for producing tea and coffee beverages. In future versions is planned to add aged alcohol and certain other beverages (because we are completely dissatisfied with the simplicity of the recipes in the existing "TFC Aged Alcohol" addon).

This is not a fork of Caffeinated or TFC Caffeine; the mod is being created from scratch.

The technical name 'jsdrinks' is derived from the project for which the addon was originally created (Journey&Settle).
